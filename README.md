## ⚡ Overview

**Lawless** is a standalone personal operational system built with a futuristic HUD interface. It combines task control, budget monitoring, and an interactive command-line AI assistant to replace generic lifestyle trackers with a sleek, low-latency workspace.

## ⚙️ Key Modules

* **Protocol:** Direct task and habit management with execution toggles and custom priority scoring.
* **Vault:** Localized asset and cashflow tracking powered by native SwiftData persistence.
* **Mentor 2.0:** Interactive CLI terminal providing real-time system diagnostics, analysis, and custom prompts.

---

## 🛠️ Tech Stack

* **UI Framework:** SwiftUI (iOS 17+)
* **Persistence:** SwiftData
* **Architecture:** Modular TabView with custom Theme Engine & Neon Glow FX
* **Language:** Swift 5.10+
